# Security Policy

## Supported versions

Security fixes are provided for the latest released version of
`rules_pylyglot`.

## Reporting a vulnerability

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/scottpledger/rules_pylyglot/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include reproduction steps, affected versions, and the expected impact when
possible. You should receive an initial response within seven days.
